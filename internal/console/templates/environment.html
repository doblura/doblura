Capacity

More than one copy needs file storage every copy can reach. The API refuses the combination that would otherwise lose attachments.

Module updates

Odoo has to be told when addon code changes: the module records in the database still describe the old code, views are not reloaded, and a new field has no column. Doblura hashes each addon's content and updates the ones that actually changed — no version to remember bumping.
On for review and QA, where a change should land without ceremony. Off for staging and production, so a schema is never rewritten because a node was drained at three in the morning.

Scheduled jobs

Off means the web pages run them too. On means the web pages stop running them entirely — it is one switch, not two settings.
